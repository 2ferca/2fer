# 2fer.ca — Canadian edition v9

Static website for GitHub Pages. Upload `index.html` to a GitHub repository and enable Pages under Settings → Pages.

## Before publishing

Set your phone number and email in `CONFIG` at the bottom of `index.html`. The booking form opens SMS/email apps; it does not submit to a server.

## v9 changes

- Restored **The Kegger** ($140 for 30–60 km), preserving the Toronto / 6ix / Hogtown / T Dot / Big Smoke description.
- Added **The Cottage Run** for Muskoka, from **$399**, with exact rate quoted depending on route. The $399 is a draft rate for southern Muskoka; review it against your driving time, round trip, vehicle costs, and load before publishing.
- Added Muskoka to the booking distance selector and live price estimate.
- Preserved the Canadian theme, animated beaver and navigation.
